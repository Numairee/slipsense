# Pygmy: No-Track Tracker (Android Edition 🐐)
> **"ปิ๊กมี่: แอปจดรายจ่ายแบบไม่จด" สำหรับผู้ใช้ Android**  
> ถอดแบบฟีเจอร์ ความเป็นส่วนตัว และประสบการณ์ใช้งานจากเวอร์ชัน iOS 100%

---

## 🌟 จุดเด่นและฟีเจอร์หลัก (100% Feature Parity with iOS)

1. **อ่านสลิปธนาคารไทยอัตโนมัติ (Automatic Thai Bank Slip Scanner):**
   - เพียงเลือกรูปสลิปจากอัลบั้ม (รองรับการเลือกทีละหลายรูปพร้อมกัน Batch Import) หรือถ่ายรูป
   - ตรวจจับธนาคาร, วันที่, เวลา, จำนวนเงิน, ผู้รับเงิน, ผู้โอน, และรหัสอ้างอิง
   - รองรับกว่า 10 สถาบันการเงินชั้นนำของไทย:
     - 💚 **K PLUS** (กสิกรไทย)
     - 💜 **SCB EASY** (ไทยพาณิชย์)
     - 🩵 **Krungthai NEXT** (กรุงไทย)
     - 💛 **Krungsri KMA** (กรุงศรีอยุธยา)
     - 💙 **Bangkok Bank** (ธนาคารกรุงเทพ)
     - 💙🧡 **ttb touch** (ทีเอ็มบีธนชาต)
     - 🩵 **MAKE by KBank** (Cloud Pocket)
     - 🩷 **Dime!** (เกียรตินาคินภัทร)
     - 🩵 **Kept by krungsri**
     - 🧡 **TrueMoney Wallet**
     - 🩷 **MyMo** (ธนาคารออมสิน)

2. **ความเป็นส่วนตัว 100% (No-Track Privacy Guarantee):**
   - ทำงานแบบ **On-Device 100%** ข้อมูลทั้งหมดและรูปสลิปประมวลผลอยู่บนเครื่องของคุณเท่านั้น
   - **ออฟไลน์ 100%** ใช้งานได้แม้ไม่มีอินเทอร์เน็ต
   - ไม่มีเซิร์ฟเวอร์ส่วนกลาง ไม่มีการเก็บ Log/Analytics
   - ฟรี 100% ไม่มีโฆษณากวนใจ

3. **ระบบให้อาหารน้องแพะปิ๊กมี่ (Feed the Goat 🐐):**
   - ตัวการ์ตูนน้องแพะแคระปิ๊กมี่น่ารัก โต้ตอบได้เมื่อแตะ มีแอนิเมชันเคี้ยวสลิป กะพริบตา
   - เอฟเฟกต์เสียงจริงสังเคราะห์ผ่าน Web Audio API (เสียงร้อง "แบะๆ" และเสียงเคี้ยวกรุบกรอบ "Nom-nom")
   - ระบบนับสถิติ Streak บันทึกต่อเนื่องประจำวัน พร้อมระดับความอิ่มท้อง (Hunger Bar)
   - หน้าห้องของน้องปิ๊กมี่ (Goat Room) สำหรับให้อาหารว่างและดูคำแนะนำการเงิน

4. **สรุปภาพรวมและสถิติการเงิน (Analytics & Insights):**
   - ยอดรวมรายจ่ายเดือนนี้ + คำนวณค่าเฉลี่ยรายจ่ายต่อวันอัตโนมัติ
   - กราฟแท่งการใช้จ่ายรายวัน (วันที่ 1 - สิ้นเดือน)
   - แผนภูมิแจกแจงหมวดหมู่ค่าใช้จ่าย พร้อมเปอร์เซ็นต์
   - วิเคราะห์สัดส่วนการจ่ายแยกตามธนาคาร/บัญชี
   - สรุป Top 10 ร้านค้าที่จ่ายบ่อยหรือยอดเยอะที่สุด

5. **ระบบจดจำร้านค้าอัจฉริยะ (Merchant Memory Rules):**
   - เมื่อคุณเปลี่ยนหมวดหมู่ของร้านค้าใด ระบบจะจดจำไว้โดยอัตโนมัติ สำหรับสลิปครั้งต่อไปที่มีชื่อร้านค้านั้น

6. **ส่งออกข้อมูล (CSV Export):**
   - ส่งออกข้อมูลเป็นไฟล์ CSV พร้อมรหัส **UTF-8 with BOM** ทำให้เปิดใน Microsoft Excel, Google Sheets, หรือโปรแกรมบนมือถือได้ทันทีโดยที่ภาษาไทยไม่เป็นภาษาต่างดาว
   - นำไปวางแผนการเงินต่อ หรือส่งให้ AI (Claude / ChatGPT / Gemini) ช่วยวิเคราะห์ได้ทันที

## 🚀 วิธีใช้งานบน Android

### วิธีที่ 1: ติดตั้งเป็นแอป Android ทันทีผ่าน Chrome (PWA - แนะนำ รวดเร็วที่สุด ⚡)
แอปถูกตั้งค่า Progressive Web App (PWA) พร้อม Service Worker สมบูรณ์แบบ:
1. สั่งรันเซิร์ฟเวอร์ในโฟลเดอร์นี้:
   ```bash
   npm run start
   ```
2. เปิดเบราว์เซอร์ **Google Chrome** บนมือถือ Android แล้วเข้าไปที่ IP เครื่องคอมพิวเตอร์ของคุณในวง Wi-Fi เดียวกัน (เช่น `http://192.168.1.XX:5173`)
3. แตะที่ **แถบแจ้งเตือน "ติดตั้ง Pygmy บน Android"** หรือแตะที่จุด 3 จุด (⋮) มุมขวาบนของ Chrome -> เลือก **"ติดตั้งแอป" (Install app)** หรือ **"เพิ่มลงในหน้าจอหลัก" (Add to Home screen)**
4. ไอคอนน้องแพะปิ๊กมี่ 🐐 จะปรากฏบนหน้าจอหลักของ Android เปิดใช้งานได้แบบ **Full Screen ไร้ขอบเบราว์เซอร์ และทำงานออฟไลน์ได้ 100%** เสมือนแอปแท้ทุกประการ!

---

### วิธีที่ 2: เปิดโปรเจกต์ใน Android Studio เพื่อบิลด์ไฟล์ APK
โปรเจกต์นี้มีโฟลเดอร์ `android/` ซึ่งเป็น Android Native Project (Capacitor) พร้อมบิลด์ได้ทันที:

```bash
# 1. บิลด์เว็บและซิงก์เข้า Android
npm run android:sync

# 2. เปิดโปรเจกต์ใน Android Studio
npm run android:open
```

ใน Android Studio:
- ไปที่เมนู **Build > Build Bundle(s) / APK(s) > Build APK(s)** เพื่อรับไฟล์ `.apk` ติดตั้งลงเครื่อง Android เครื่องไหนก็ได้ทันที!
